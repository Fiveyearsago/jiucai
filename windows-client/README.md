# Beauty 注册助手 · Windows 11 预览版

本目录是独立的 Windows 版移植工程，目标为 Windows 11 x64。Windows 版尚未在 Windows 实机上验证，不能视为与 macOS 版功能一致的正式发布版本。

## Windows 使用

将 ZIP 完整解压到本地文件夹，双击其中的 `Beauty 注册助手.exe`。保留同目录的所有文件，不要只复制 exe。测试前先确认目标站点允许注册，并在使用临时邮箱前自行阅读和同意其服务条款。

## 现有功能

- 单个账号请求验证码和手动确认注册；批量顺序注册；自动读取 Fviainboxes 新的验证邮件，也可手动输入验证码。
- 粘贴 SOCKS5 代理，支持 `host:port` 或 `host:port:user:password`，启用后可按成功账号数轮换；可逐个测试代理。
- 遇到 HTTP 429 时遵守 Retry-After 或服务器给出的等待时间；无等待提示时等待 60 秒。冷却保存在本地，重启后继续等待；不会通过切换代理或请求头跳过冷却。
- 配置请求头，查看请求摘要；注册记录、待核对状态与 CSV 导出；密码保存在本机应用数据文件中，不写入导出的 CSV。
- 发出注册提交前先保存提交状态；结果不明时须先核对，不会自动重提。

## 尚未完成

- 已支持从 HTTPS 来源定时更新代理并逐个测速；默认关闭自动更新。与 Mac 版不同，更新期间不能同时运行注册任务，尚未支持后台并发测速和注册失败后自动更换可用代理。
- macOS 版的记录详情、完整网络请求头详情、网页面板、连接检查和部分设置尚未移植；历史数据不自动从 Mac 导入。
- 当前失败账号不会像 Mac 版一样持续自动重试。界面和行为未经 Windows 实机验收。
- 本预览包为未签名的 Windows 便携 ZIP，不是正式安装程序；目前使用 Electron 默认图标。分发前应先完成 Windows 测试、签名和安装包制作。

## 构建

需要 Node.js 22 或更新版本：

```sh
npm ci
npm test
npm run package:win
```

Windows 数据保存在当前用户的应用数据目录，包含明文密码及代理认证信息，请仅在可信设备上使用。
