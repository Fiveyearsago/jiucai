# Beauty 注册助手（macOS）

原生 SwiftUI + WebKit 客户端，将韭菜盒子注册页和 Fviainboxes 邮箱整合在一个窗口中。适用于 macOS 13 及以上；当前构建适用于 Apple Silicon。

## 运行

双击 `dist/Beauty 注册助手.app`。从源码构建需要 Xcode Command Line Tools：

```sh
./scripts/build-app.sh
```

1. 设置用户名前缀、起始编号、数量、密码和邀请码。根据现有截图，初始建议编号为 176，请按实际账号使用情况调整。
2. 阅读邮箱服务条款，勾选同意后点击“开始注册”。默认每次 1 个账号，账号之间间隔 60 秒，可设置为 3–3600 秒。
3. 应用填写邮箱和注册表单，发送验证邮件。发送成功后等待 2 秒点击“Get Email”，未取得验证码时每 2 秒继续获取；新邮件返回后每约 0.2 秒检测并读取正文，取得验证码后停止刷新并提交注册。如需人机验证或网站条款确认，在内嵌页面完成后点击“继续任务”。
4. 无法自动识别邮件时，可打开邮件正文，并在应用右上方输入 6 位验证码（支持字母和数字）。
5. 在“注册记录”查看结果或导出 CSV。“记录目录”可打开本地文件夹。
6. 侧边栏“请求头”可独立选择浏览器标识（Safari 兼容 / 默认 WebKit）、语言（网页默认 / 简体中文 / 英文）、响应格式（网页默认 / JSON / JSON 与文本）。默认保留 Safari、英文、JSON；配置自动保存，下一次打开页面或开始任务生效，任务运行期间不能更改。“任务 → 使用 Safari 浏览器标识”只切换浏览器标识，语言和格式保持所选值。邮箱页面保持默认设置。
7. “当前页面配置”显示已应用的 User-Agent、Accept、Accept-Language；未加载网页时显示待应用配置，切换后尚未重载时分别标明当前值和待生效配置。默认字段未显式覆盖时显示由网页或浏览器设置，不猜测具体值。
8. “请求详情”保留本次运行最近 20 条注册页导航及状态/验证码/注册接口请求，可选择查看方法、路径、时间、配置和可观测的字段。字段包括 User-Agent、Accept、Accept-Language、Content-Type、Cache-Control、Pragma、X-Requested-With、Origin、Referer，并区分网页设置、客户端配置、浏览器标识及导航请求来源。没有观测到的字段不显示，浏览器自动生成但未暴露的头不作推测；这不是完整网络抓包。

## 行为与数据

- 串行执行；暂停后不发起新的流程动作，已经发出的网络请求仍可能完成。
- 单次注册数量不再限制为 100，可输入正整数；仍校验整数溢出及网站要求的用户名长度。大批量只规划编号范围，到执行某个账号时才创建记录，未开始的账号不提前占用记录和内存。
- 注册工作台保留统计与网页区域，运行状态显示在底部；邮件验证期间可在网页工具栏手动输入验证码。
- 邮箱页自动隐藏顶部、侧栏、邮件区域和底部悬浮广告，并收起广告预留空间；保留邮件正文、服务条款及人机验证。
- 发送验证码明确返回 HTTP 429 时，按 Retry-After 或“等待 N 秒/分钟”提示倒计时，再重试当前账号；连续限流至少等待 5、10、20 秒，最多重试 3 次。服务端要求更长时间时遵守该时间，超过一小时则停止并提示稍后再试。暂停和停止会阻止继续发送。
- 发送结果未知、网络超时、其他错误及注册提交失败仍会停止，不自动重发或重新提交注册。
- 网站拒绝发送验证码或注册时，弹窗及注册记录显示 HTTP 状态和经过脱敏的服务器说明，方便判断重复账号、验证码失效、频率限制等具体原因。
- 只有 `/api/user/register` 返回 HTTP 成功且 `success: true` 才记录成功。跳到登录页本身不作为成功证据。
- 提交前先原子保存本地状态。提交超时、退出中断会标记为“结果待核对”；该用户名不会被自动重复提交。需要先在官网核对。
- 核对后，在记录列表选中“结果待核对”的账号，点击“记录核对结果”，可标记成功或允许重新创建任务。
- 自动读取邮箱只匹配时间不早于本次发送、且主题/发件人带有韭菜盒子或 New API 标识的验证邮件；已知旧邮件排除，没有时间信息的邮件可手动输入验证码。
- 收码期间持续轮询，直到取得验证码或用户停止；暂停时不再主动获取邮件，邮箱限流或人机验证会暂停等待处理。确认发送成功后仅重复获取收件箱，不重发验证码。
- 注册密码输入后以明文保存到本机应用数据目录的私有文件，目录权限为 0700、文件权限为 0600，启动时自动恢复；密码框下方显示保存状态。清空密码框会删除本地文件。新版不访问钥匙串，旧版保存在钥匙串的密码不会自动迁移，需重新输入一次；旧钥匙串项目可在“钥匙串访问”中手动删除。
- 密码不写入配置、记录、日志或 CSV。WebKit 使用临时会话，不复用浏览器登录信息。
- 请求详情仅保存在运行内存中，不记录查询参数、请求正文、Cookie、Authorization 或任意自定义凭据头；Origin/Referer 移除查询及未知路径，已知敏感输入脱敏。兼容配置存入本机应用偏好设置。
- 截图仅在明确成功且跳转登录页后保存，避免截到注册密码或验证码。
- 数据位于 `~/Library/Application Support/BeautyRegistration/`，包括 `records.json` 和成功截图。应用初次启动不导入旧截图，也不推断旧账号的成功状态。
- Fviainboxes 为公开临时邮箱，不适用于敏感账号。客户端保留原网页的验证和条款交互。

## 验证

```sh
swift test
node --test scripts/bridge.test.cjs
```

应用使用网站公开页面，页面字段或接口改变后可能需要更新 `Resources/bridge.js`。网页加载、源码与接口适配可独立检查；完整注册需要实际接收验证码并取得服务器回执。

本地构建使用 ad-hoc 签名，未做 Apple Developer ID 签名或公证。分发到其他 Mac 前需要正式签名、公证，并分别构建相应架构。
